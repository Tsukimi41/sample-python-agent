# 資料調査と議論記録

## 1. 参照資料

### 『人狼知能プロジェクト』（片上ほか、2015）

重要な出発点は、人狼には全員が共有できる客観的情報がほとんどなく、自分の役職すら他者へ客観的に証明できないという「客観的視点での情報非決定性」である。プレイヤーは発言者の立場と文脈から発言の尤度を自分で決める必要がある。また、推理は他者意図のモデル化、説得は「他者から見た自己」のモデル化として整理されている。

特に設計へ直接効く表現は、村人は可能性の枝を刈り、人狼は枝を育て、論理と説得によって枝が減増するという捉え方である。これは可能世界分布、制約、説得効果を同じ状態表現の上で扱う動機になる。また、本物の占い師も常に真実を言うとは限らず、人狼は真の役職者を正確に模倣できるため、発言を0/1の真偽規則にしない根拠になる。

5人人狼では、真占い師が実際には占っていない村人へ人狼判定を出すことが村側に有利になり得る例も紹介される。これは「真役職なら真実を言う」という単純モデルが戦略を損なう具体例であり、真偽と役職と意図を分離すべき理由である。

### 『人狼知能研究のすすめ』（片上ほか、2018）

人狼知能大会と関連研究を、ゲーム理論・戦略、役職推定、発言生成、非言語・HAIなど広い観点から概観している。大会という共通評価基盤があること、プロトコル部門と自然言語部門を段階的に扱えること、役職推定だけでなく対話・身体性・エンターテインメントまで研究対象が広がることを確認した。

今回の判断では、この広がりを一度に実装対象にせず、後続研究が共有できる状態表現を先に作る、という優先順位に使った。

### 『深層学習による役職推定を用いた人狼知能エージェントの研究』（早稲田ほか、2020）

5人人狼で、人狼・占い師・狂人を一度に推定する多層パーセプトロンを提案している。従来モデルに対して、人狼推定は71.1%から72.3%、占い師推定は65.1%から68.3%、狂人推定は73.1%から73.6%へ改善した。一方、提案エージェントの勝率は46.7%から45.3%へ下がった。論文自身も、今後の課題として相手の行動パターン学習や説得戦術を挙げている。

この結果から、「推定器の精度」と「その推定を使う戦略」の評価を分離する。また、accuracyだけでなく確率較正を測り、投票方策まで含むアブレーションを必須にする。

### “Toward development of logical model and abductive inference method of Werewolf agents with uncertain beliefs”（Takada and Toda, 2024）

不確実な信念を持つ人狼エージェントをBDI論理でモデル化し、他者の私有情報を仮説推論するため、BDI式を可能世界を明示した一階述語論理へ変換する方向を示している。例として、信念 `BEL`、欲求 `DESIRE`、意図 `INTEND` と発話行為を結び、Python/pyparsingとOpen-Davidを使う構想が記されている。

今回のMVPは論文の完全なBDI・仮説推論を再実装するものではない。ただし、(1) 世界を明示する、(2) 信念と意図を将来分離できるデータ構造にする、(3) 私有情報推定を後から載せられる、という設計方向を採用する。

## 2. 資料横断の統合

4資料を時間順に見ると、次の流れが見える。

1. 2015: 人狼の本質を、客観的非決定性、他者意図、他者から見た自己、可能性の枝として定式化する。
2. 2018: 大会と研究領域が広がり、役職推定・対話・戦略・HAIなど複数の実装経路が成立する。
3. 2020: 深層学習で役職推定精度を改善しても、勝率が改善しないという統合上の課題が現れる。
4. 2024: 不確実な信念、BDI、可能世界、仮説推論を接続する論理的な方向が提案される。

したがって、「深層学習か、論理か、確率か」という二者択一にはしない。最初に論理制約つき可能世界分布と説明証跡を作り、後から深層モデルを尤度関数、BDIを意図モデル、決定理論を行動選択として接続する。

## 3. 現在コードの観察

- `villager.py` はCO、占い報告、霊媒報告を時系列リストへ保存する。
- 候補選択は最終的に `random.choice` であり、同じ状態でも行動が変わる。
- 他者の報告はルールベースで利用するが、発言者が各役職である可能性の共同分布はない。
- `possessed.py` の偽判定は確率0.5、`werewolf.py` は人間への黒判定を確率0.3で選ぶ。
- 偽判定数の上限という局所制約はあるが、騙り世界、過去主張、将来説明まで含む一貫性はない。
- 推定根拠・候補選択理由を外へ返す構造がない。

このため、ユーザーが挙げた「確率で状態推定はよいが行動を確率化しない」「嘘に一貫性を持たせる」「説明可能にする」という三点が、現在コードとの差分として明確である。

## 4. 議論ログ 2026-09-15

### 発散時の中心論点

- 役職推定だけでは人狼知能の全体ではない。
- しかし、相手視点、説得、欺瞞のすべてに「どの世界が成立するか」という基盤が必要。
- 独立な役職分類は役職数制約を壊しやすい。
- 発言を真実として取り込む設計は、人狼のゲーム性そのものを消す。
- 行動の乱数は、不確実な信念と不確実な方策を混同する。
- 説明は確率の横に自然言語を置くだけでは不足し、実計算の証跡が必要。

### 収束時の判断

第一候補を「説明可能な可能世界ベース役職推定器」とした。第二候補は「一貫した偽占い管理器」。前者を先にする理由は、後者が必要とする整合世界の判定基盤を提供し、さらに投票、相手視点、説得へ再利用できるからである。

### 根底原則の追記: 確率は理由ではない

ユーザーから、説明可能性について重要な修正があった。求める説明は「こういう確率が出たから、この判断をした」という数値の読み上げではない。確率は複数の不確実な証拠を統合した計算結果であり、自分の候補選択には使えても、他者を効果的に説得する理由としては不十分である。

人狼は対話と多数決のゲームなので、正しく推定するだけでは足りない。相手も観測できる事実、ゲーム上のルール、発言間の整合・矛盾、残る代替仮説を示し、「どうしてその判断へ至ったか」を相手が検討できる形にする必要がある。このため説明可能性を、内部モデルの監査機能だけでなく、将来の説得・反論・議論を成立させる中核機能として扱う。

設計上は、内部計算へ忠実な監査用説明と、相手が知り得る情報だけで構成する対話用説明を分ける。対話用説明は、主張、共有可能な根拠、根拠と主張を結ぶ保証、代替仮説、想定反論から構成する。確率は最後に不確実性の要約として添えてよいが、根拠の代わりにはしない。この原則は、思想文書の公理、説明機能要件、受入れ条件、評価指標へ反映した。

### 未決事項

1. 最初のデモを村人の投票にするか、狂人の偽占いにするか。
2. 手動尤度の値を、文献、ログ頻度、直感のどれから初期化するか。
3. 5人版だけで論文上十分な問いになるか、15人版の近似推論まで必要か。
4. 説明の評価を、忠実性だけでなく人間の納得度まで実施するか。
5. 「行動を確率的にしない」を学習時の探索にも適用するか。本番方策は決定的とし、訓練中探索は別扱いにする案が妥当だが、方針確定が必要。
