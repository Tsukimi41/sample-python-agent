# 思想と設計原則

## 1. なぜ人狼知能を作るのか

人狼は、盤面だけを探索すればよいゲームではない。各人が異なる情報を持ち、発言は事実の報告であると同時に、推理、説得、観測、牽制、協調、偽装、時間稼ぎでもある。しかも最後は多数決で共同の行動を決める。したがって、人狼知能は「隠れた正解を当てる分類器」ではなく、異なる認識を持つ複数主体の中で、何を信じ、何を疑い、何を語り、相手の認識をどう動かすかを扱う人工知能である。

最初から勝率だけを最大化すると、なぜ勝ったかも、何を学んだかも説明できないエージェントになりやすい。本プロジェクトでは、強さと同時に、推論過程を人が検査できることを価値とする。発表時には「確率が0.72になった」ではなく、「どの可能世界が、どのルールと観測で消え、どの発言をどう解釈し、どの対立仮説と比較した結果、その判断へ至ったか」を示したい。

ここで、確率は結論の要約にすぎない。「Agent[03]が人狼である確率は72%」という数値は、エージェント自身が候補を順位付けするには使えても、他者を説得する根拠としては弱い。人狼は多数決であり、正しい対象を一人で見抜くだけでは勝てない。他者が確認できる観測、共有できるルール、主張同士の矛盾、代替仮説との比較を示し、相手がその推論を検討できて初めて、判断は対話上の効力を持つ。したがって説明可能性は、モデルを外から監査するための付加機能ではなく、他者の信念と投票を動かすための中核能力である。

## 2. 人狼知能について置く公理

### P1. 発言は事実ではなく観測である

「Agent[02]は占い師だ」と発言したという事実と、Agent[02]が実際に占い師であることを分離する。前者は確定した出来事、後者は仮説である。発言をそのまま状態へ書き込まない。

### P2. 真偽と意図は別の軸である

真の発言でも、情報提供、反応観測、信用獲得、仲間切りなど意図は異なり得る。偽の発言でも、長期的な騙り、短期的なブラフ、推理途中の誤り、言い間違いは異なる。最低限、`truth_value` と `speech_act/intention_hypothesis` を別に表現する。

### P3. 個人別の視点を混ぜない

世界の真の役職、自己が知る情報、公開情報、ある他者が知り得る情報は別である。実装上も、全知のゲーム状態を推論器に誤って渡さない。これは情報漏洩防止の要件である。

### P4. 役職は同時割当てである

各人の「人狼確率」を独立に出すだけでは、役職数制約や相互排他性を壊す。まず有効な役職割当て世界に分布を持ち、そこから個人別確率を周辺化する。

### P5. 確率は信念表現に使い、行動の抽選には使わない

不確実性は分布で保持してよい。しかし同じ状態・同じ設定・同じ履歴なら、同じ行動を返す。行動は期待効用、最悪時後悔、情報価値など明示された評価値を決定的に比較して選ぶ。同点時も固定された規則で解消する。

### P6. 時点を失わない

同じ発言でも、初日冒頭、対抗CO後、投票直前では意味が違う。すべての観測は `day`, `turn`, `phase`, `talk_index` を持ち、更新前後の信念スナップショットを追跡可能にする。

### P7. 嘘は一つの代替世界にコミットする

長期的な騙りは、その場ごとに都合よく出力する乱数ではない。騙るなら、主張上の役職、過去判定、未判定者、味方・敵の位置付け、将来起こり得る公開事実が両立する「語り世界」を持つ。ブラフとして撤回する場合も、撤回理由と発話目的を記録する。

### P8. 説明は後付け文章ではなく推論の副産物である

説明文だけを生成モデルに作らせない。制約適用、尤度更新、世界除外、仮説比較、行動得点の各段階で根拠データを残し、それを文章化する。

### P9. 確率は結論であり、理由ではない

確率が高いことを、その判断の根拠として語らない。「72%だからAgent[03]へ投票する」は内部の選択規則の説明にはなっても、なぜAgent[03]を疑うべきかという理由にはならない。必要なのは、例えば「Agent[03]の占い結果は昨日の主張と両立しない」「Agent[03]が真占い師の世界では、既知の役職数制約と衝突する」「対立するAgent[02]真の世界ではこの投票行動を一貫して説明できる」といった、観測から結論へ至る推論である。確率はその複数根拠を統合した最終値として添える。

### P10. 説明には監査用説明と対話用説明がある

監査用説明は、内部計算へ忠実で、すべての証拠、重み、除外世界を追跡できなければならない。対話用説明は、公開可能な情報だけを使い、相手が理解・確認・反論できる論証でなければならない。対話用説明は単なる監査ログの短縮ではない。相手が何を知り、何を疑い、どの前提なら受け入れられるかを考え、主張、根拠、根拠から主張へ進む保証、想定反論、代替仮説を組み立てる。ただし、説得のために内部推論と無関係な理由を捏造してはならない。

### P11. 説明は相手と議論可能でなければならない

良い説明とは流暢な文章ではなく、相手が「その観測は違う」「別の世界でも説明できる」「そのルール適用はおかしい」と具体的に反論できる説明である。反論を受けたら、争点となった前提を特定し、信念を再計算するか、なぜ維持するかを答える。説明は一方向の出力ではなく、共同で可能性の枝を検討する対話単位として設計する。

### P12. 推定精度とゲームの強さを同一視しない

役職推定が正確でも、その情報を投票・発言・能力行使に適切に変換できなければ勝率は上がらない。推定器単体の評価と、方策へ接続した評価を分ける。

### P13. ルールは暗黙のif文ではなく制約として表現する

役職数、生存条件、占い結果、処刑・襲撃可能性、COと報告の整合などを名前付き制約にし、どの制約が世界を除外したか説明できるようにする。

## 3. 自分視点と相手視点

必要な視点を次の4層に分ける。

1. **実世界**: 対戦サーバだけが知る完全状態。学習・試合後評価以外では参照禁止。
2. **自己信念**: 自分の役職と私有情報、公開履歴から構成する世界分布。
3. **公開信念モデル**: 公開履歴だけを知る合理的観測者が持ち得る世界分布。
4. **他者から見た自己**: 各他者が自分を各役職だと思う度合いの推定。

MVPは2を完全実装し、3を同じ推論器の入力差し替えで実装する。4は、相手の私有情報を断定せず、「各可能世界においてその相手が知るはずの情報」を条件分岐して集約する近似から始める。二階信念 `私は、相手が、私が…と信じると信じる` は計算量と検証難度が急増するため、最初は深さ1で止める。

## 4. 目指さないもの

- 確率をもっともらしく出すだけで、制約違反を許すモデル
- 「確率が高いから」としか理由を述べられないモデル
- 発言を全面的に真または全面的に偽と決め打ちするモデル
- 毎回乱数で投票・襲撃・偽判定を決めるモデル
- 勝率だけを報告し、推定較正や説明忠実性を測らない研究
- 全問題を一度に深層学習・強化学習へ押し込む実装
- 後から作った説明文で、実際の判断経路と一致しない説明
- 相手に見えていない私有情報を、説得理由として不用意に開示する説明
- 相手を動かせればよいとして、内部判断と無関係な根拠を捏造する説明

## 5. 長期的な研究像

基盤は、時系列イベントと可能世界分布である。その上に、意図推定、他者信念、説得効果予測、発言計画、整合的な嘘、キャラクター性、学習を段階的に載せる。確率モデル、論理モデル、決定理論、機械学習のどれか一つを信仰するのではなく、役割を分担させる。

- 論理・制約: 不可能な世界を除く
- 確率: 残った世界の不確実性を表す
- BDI/意図モデル: 発言を生む理由を表す
- 決定理論: 分布から決定的な行動を選ぶ
- 学習: 尤度・重み・相手固有傾向をデータから調整する
- 自然言語生成: 根拠構造を、人が理解し他者を動かせる発言に変換する
