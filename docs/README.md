# 人狼知能AI 研究・設計ノート

このディレクトリは、実装だけでは失われやすい「なぜそれを作るのか」「何を人狼知能の本質とみなすのか」「どの代案をなぜ採用・保留・棄却したのか」を、発表資料に再利用できる粒度で残すための記録である。

## 現在の結論

最初に実装する一機能として、**説明可能な可能世界ベース役職推定器**を第一候補とする。

これは各プレイヤーの役職を別々に当てる分類器ではない。ゲームの役職構成、公開情報、自己だけが知る情報、発言、投票、襲撃、処刑、時刻を受け取り、成立し得る「役職割当て全体」を列挙または圧縮表現し、各世界の重みを更新する。その結果から役職確率を周辺化する。ただし、**確率は計算結果であって、判断理由そのものではない**。説明では、観測事実、適用したルール、発言の解釈、残った対立仮説、それらから結論へ至る論理のつながりを示す。さらに将来の対話では、その根拠を相手が確認・反論できる議論へ変換し、相手を説得するために用いる。

最初の対象は5人人狼（村人2、占い師1、狂人1、人狼1）とする。これは世界数が小さく、全列挙による正解系を作れ、説明可能性とテスト可能性を確保できるためである。
